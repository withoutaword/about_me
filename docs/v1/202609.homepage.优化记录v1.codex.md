## 优化目标

将网站从个人主页升级为面向海外 AI Engineer / Agent Systems 岗位的职业 Portfolio，让招聘者快速理解 Bruce 的技术定位、职业经历、项目成果与可信度证明，同时保留克制的视觉风格和个人表达。

## 已完成

### 首页定位与成果

- Hero 明确定位为 `AI Engineer · Agent Systems`，主张为 “Building reliable systems for models and agents.”
- 专业方向收敛为 Agent Systems、Agent Evaluation 和 AI Infrastructure。
- 首页 CTA 调整为 Projects、GitHub 和 CV，均使用真实链接。
- 增加已确认的结果指标：`2 days → 10 min`、`6+ Agent Engineering Skills`、`2× Quarterly Recognition`。
- 增加 Featured Projects，直接展示 Agent Evaluation Platform 与 Agent Engineering Skills。
- 增加真实 Email 联系入口。

### 信息架构

- 导航调整为 `About → Projects → Career → Writing → Patents → Awards → Photography`。
- `Articles` 对外统一命名为 `Writing`。
- 隐藏 Moments 与 Beliefs，并保留源码以便将来恢复。
- 新增 Projects、Writing、Patents、Awards 的 Markdown 列表页和详情页。
- 所有内容目录均在构建时自动生成索引。

### Career

- 根据 CV 补全完整职业轨迹：Chow Tai Fook、IBM、Fenqile、vivo。
- 每段经历增加职责概述、Selected Impact 和能力标签。
- 消除 2018–2021 履历断层。
- vivo 经历重点展示 Agent Evaluation、Agent Skills、LLM 和推荐系统经验。

### Projects

- 两个核心项目改为 English-first Portfolio Case Study。
- 采用 Problem、My Role、Architecture/Approach、Key Decisions、Impact、Lessons Learned 结构。
- 明确 Technical Lead / Architect 角色及已确认成果。
- 支持 Markdown、Front Matter、架构图和 Obsidian 图片语法。

### Awards、Patents 与 Writing

- `Star Of Season` 统一为 `Quarterly Star Award`，重写不自然英文。
- 保留奖状原图，并增加英文 Recognition、Contribution 和组织信息。
- Patents 自动提取专利号、摘要和 Google Patents 官方链接。
- Writing 增加 `Engineering`、`Essays`、`Life` 分类筛选。
- 中文或英文个人文章均可保留，核心职业页面采用英文。

### 品牌、SEO 与性能

- 修复站点名称、Description、favicon 和失效社交链接。
- 各列表页和详情页拥有动态 Title、Description、Canonical、Open Graph 与 Twitter Card 元数据。
- 构建时自动生成 `sitemap.xml` 和 `robots.txt`。
- 新增英文 404 页面。
- CV 固定使用 `/info/CV.pdf`，后续替换文件无需修改代码。
- Photography 使用本地目录自动索引、自适应列表和大图预览。
- 为现有照片生成 640px 缩略图，列表资源由约 18 MB 降至约 629 KB；点击后才加载原图。
- Default、Cyber、INS 三套主题均已适配主要页面。

## 部分完成

### Projects 作为核心证据

现有两个项目已有标准 Case Study，但建议中的第三个旗舰项目 `LLM Inference Benchmark` 尚未创建。项目卡片也尚未绑定对应公开 GitHub 仓库，代码证据链仍不完整。

### Patents 可读性

专利列表已经截短 Abstract，但仍主要依赖专利原文自动摘要；尚未为每项专利单独编写面向非专利读者的 `What it solves`。

### 国际化

Career、Projects、Patents、Awards 和网站 UI 已 English-first。Writing 允许中英文混合，但尚未提供语言标识、中文/英文配对关系或语言筛选。

### SEO

客户端已动态更新页面元数据，但网站仍是纯 SPA。部分社交平台或搜索爬虫不会执行 JavaScript，因此详情页分享时未必能获得动态标题；后续需要预渲染或 SSR 才能彻底解决。
